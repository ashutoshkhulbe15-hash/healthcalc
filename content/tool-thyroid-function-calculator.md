# Compare thyroid results with the laboratory's reference intervals

Enter a TSH result and the lower and upper reference limits printed on the same laboratory report. Free T4 is optional; if supplied, enter its result and both reference limits using the same units as the report. The calculator only states whether each value is below, within or above the entered interval. It does not diagnose or recommend treatment.

## Interpretation limits

The American Thyroid Association describes TSH as the usual initial blood test for thyroid function and notes that free T4 is interpreted alongside TSH. Results can be affected by context: for example, pregnancy changes thyroid test results and requires pregnancy-specific, ideally trimester-specific intervals. The lab's assay, medicines and clinical history matter. [American Thyroid Association: Thyroid Function Tests](https://www.thyroid.org/thyroid-function-tests/); [ATA: Hyperthyroidism in Pregnancy](https://www.thyroid.org/hyperthyroidism-in-pregnancy/)

A result within a supplied interval does not by itself resolve symptoms or a discordant set of results. Discuss results with a healthcare professional, especially during pregnancy. Do not use this comparison to select or change medication.
