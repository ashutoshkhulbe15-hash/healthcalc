# Body frame size calculator — calculation withdrawn

The site's wrist-to-height frame-size calculation and related weight-adjustment guidance have been withdrawn. The existing page description, wrist table and calculator used different methods, so the displayed category could not be tied to a single verified source and matching calculation.

No frame classification or weight target is shown while the method and its source remain unverified. The page can be reconsidered if an exact, relevant source and matching implementation are established.
